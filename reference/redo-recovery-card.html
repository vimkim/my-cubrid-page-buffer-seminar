Checkpoint ownership

  • Page buffer: selectively flush qualifying pages; report remaining redo floor.
  • Log/filesystem/volume owners: checkpoint records, WAL/header state, filesystem sync, metadata boundaries.

Checkpoint ≠ flush every page.

Generic redo route

  1. Fix RECOVERY_PAGE, WRITE.
  2. Absent/deallocated target → skip, no debt.
  3. record_lsa <= page_lsa → skip/unfix.
  4. Newer record → callback.
  5. Set page LSA and DIRTY.
  6. Release on every exit.
