Objects and lifetimes

VPIDLogical identity value; may exist without residency.
BCBReusable pool control; current identity can change.
FrameReusable pool bytes; contents follow resident generation.
PAGE_PTRBorrowed view; use ends at matching unfix.
Global fcntAll granted fix debt for one BCB.
Thread holderThis thread's BCB debt and nested fix_count.

Four-coordinate worksheet

  1. Identity / residency: which VPID does this BCB/frame represent?
  2. Ownership: which fixes prevent ordinary reuse?
  3. Concurrency: who may inspect or mutate bytes now?
  4. Durability / propagation: which generation needs propagation, and what recovery boundary exists?

Three lifetimes

  • Pool: BCB and frame allocation.
  • Resident generation: current VPID-to-frame meaning.
  • Borrow: one successful fix through matching unfix.

Four anti-synonyms

  • Fixed is not resident.
  • DIRTY is not durable.
  • Unfix is not flush.
  • Eviction is not deallocation.
