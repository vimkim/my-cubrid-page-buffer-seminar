The lesson loop

Use the same five moves every time

1

Acquire

Read the short lesson and inspect its one primary diagram.

2

Close

Hide the page before attempting the retrieval prompt.

3

Retrieve

Predict state and consequences from memory; do not reveal first.

4

Submit

Paste the answer into chat for source- and invariant-level feedback.

5

Record

Create a learning record only after demonstrated understanding, then interleave it later.

Use printable reference cards after learning, not as a substitute for retrieval. Use canonical Markdown when tracing source or preparing team questions.

Presentation gate

Understanding is necessary; rehearsal proves delivery

  1. Deliver the six-move page journey without notes.
  2. Navigate from a claim to its canonical page and pinned source range.
  3. Answer counterexamples across identity, ownership, dirty generation, and replacement axes.
  4. Distinguish contract, verified mechanism, policy, inference, runtime observation, and historical evidence.
  5. Defend one change-impact case under adversarial questions and record teammate feedback.
