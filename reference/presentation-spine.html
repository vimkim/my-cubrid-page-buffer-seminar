The opening contract

Logical identity + access intent → resident bytes + page latch + recorded fix debt → borrowed PAGE_PTR until matching unfix.

The Module does not finish logical locking, record validation, recovery logging, page LSA, dirty marking, or caller cleanup.

1–3 · Borrow correctly

  1. Objects: VPID → BCB ↔ frame → PAGE_PTR; global fcnt; per-thread holder.
  2. Acquire/release: hit and miss preparation converge on one ownership postcondition; each success creates one release debt.
  3. Caller: logical lock, validate, mutate, log, set page LSA, dirty, and clean up every exit.

4–6 · Propagate and change safely

  1. Flush: copied generation G, WAL gate, DWB/direct-write boundary, concurrent G+1 re-dirty.
  2. Replace: eligibility before policy; unfixed alone is insufficient.
  3. Defend: Interface, owner, invariant, negative path, caller impact, verification seam.

Four anti-synonyms

  • Fixed is not resident.
  • Dirty is not durable.
  • Unfix is not flush.
  • Eviction is not deallocation.

Six evidence labels

  • Interface contract
  • Verified mechanism
  • Implementation policy
  • Inference
  • Runtime observation
  • Historical evidence
