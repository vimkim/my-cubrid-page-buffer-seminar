Cardinality & sizing

pgbuf_Pool은 server 프로세스당(=DB당) static 전역 1개. 기본값: data_buffer_size 512MB ÷ IO_PAGESIZE 16KB = num_buffers 32,768 (PRM_ID_PB_NBUFFERS).
