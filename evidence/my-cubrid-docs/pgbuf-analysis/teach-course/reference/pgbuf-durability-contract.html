Concurrency, recoverability, propagation

WRITE fix, durable WAL, data-page flush를 한 단어 “durability”로 뭉개지 않기 위한 발표용 contract card.

Pinned: f799e05CUBRID-C004Offline

Three clocks

Safe sentence

WRITE fix는 memory access 권한이다. 필요한 WAL과 commit record가 durable하면 data page가 아직 old여도 redo로 복구할 수 있다. Page flush는 나중에 WAL-before-data를 지키며 image를 전파한다.

Dangerous sentence

“WRITE latch를 얻었으니 durable하다”와 “commit 전에 dirty page를 반드시 flush한다”는 둘 다 틀리다. 전자는 WAL을 생략하고, 후자는 WAL이 제공하는 deferred writeback을 없앤다.

Writer contract

  1. WRITE ownership 아래에서 page bytes를 수정한다.
  2. Recovery log와 page LSA 관계를 만든다.
  3. Resident generation을 DIRTY로 추적한다.
  4. Fix ownership을 정확히 release한다.

Flusher contract

  1. 한 dirty generation을 snapshot한다.
  2. Snapshot page LSA까지 WAL을 force한다.
  3. DWB 또는 data volume에 image를 쓴다.
  4. Concurrent re-dirty를 clear하지 않는다.
  5. 일반 I/O error면 old DIRTY/LSA를 복원한다.
