Failure postcondition boundary — CUBRID-C010/C012. Caller가 NULL을 받으면 PAGE_PTR ownership은 없으므로 unfix하지 않는다. 그러나 current revision의 모든 failure가 internal accounting을 원상복구한다는 뜻은 아니다. DWB read direct error는 common provisional cleanup 전에 return한다. Normal idle/compatible/blocked grant와 lock-free READ는 latch/fcnt commit 뒤 holder allocation 실패에서 그 state를 backout하지 않는다. Strict-compatibility 구현은 이 behavior를 명시해야 하며 hardened 구현은 BCB/VPID와 latch/fcnt rollback 또는 holder reserve-first를 제공해야 한다.

Configuration은 semantics를 바꾸지 않는 policy seam과 failure semantics를 바꾸는 latch-timeout seam으로 나눈다. Transaction lock은 page buffer 밖에서 logical visibility/conflict를 책임진다. Page buffer는 record/page-type correctness를 추론하지 않는다.

Page-latch deadlock detector는 보장되지 않는다. Bounded timeout은 termination cap이며 proof가 아니다. Starvation은 waiter no-barging과 promoter-front policy로 완화되지만 strict FIFO는 아니다.

Checkpoint, crash, recovery와 idempotence

Crash/partial failure matrix
Failure point Durable state Volatile loss/cleanup Restart rule
dirty before WAL durable old data, maybe partial log BCB/hash/holder lost uncommitted/invalid log ignored or undo; no page-ahead guarantee
WAL durable, data old redo sufficient dirty metadata lost record LSA > page LSA이면 redo
DWB durable, home torn DWB copy + log volatile state lost DWB recovery before log redo
home write complete page image LSA L resident may have later dirty generation redo records ≤ page LSA skip
ordinary write error old home image flusher restores dirty/oldest LSA later retry/checkpoint
clean shutdown log/data/volumes flushed by log_final pool destroyed only afterward normal boot

Checkpoint는 log를 target LSA까지 force하고 eligible dirty permanent BCBs를 oldest-unflush-LSA로 collect/sort/flush한다. Concurrent modification 때문에 같은 page를 다시 flush할 수 있다. Redo idempotence는 record LSA와 page LSA 비교다. Recovery의 volatile hash, holder, waiter, LRU는 복원 대상이 아니라 initialization으로 재생성된다.

Replacement/flush policy pseudocode, cost와 pathology

allocate_bcb(vpid):
  if invalid_list not empty: return pop()
  for private/shared victim sources:
    candidate = scan LRU tail up to configured max depth
    lock candidate
    if zone3 && fcnt==0 && clean && !flushing && no_waiter:
      remove hash; set INVALID; return candidate
    unlock and continue
  request victim/flush daemon progress
  bounded wait or ER_PB_ALL_BUFFERS_DIRTY

flush_snapshot(bcb):
  require copy-safe latch and !FLUSHING
  set FLUSHING; clear old DIRTY; copy bytes + page_lsa + oldest_lsa
  unlock BCB
  force WAL(page_lsa)
  submit DWB or direct write
  relock; on ordinary error restore dirty/oldest_lsa
  clear FLUSHING; preserve concurrent DIRTY; wake flush waiters

LRU scan cost는 candidate depth에 비례하고 hash lookup은 평균 O(1)이다. lru_hot_ratio, lru_buffer_ratio, num_LRU_chains, max_depth_of_searching_for_victims_in_lru_list, data_buffer_flush_ratio가 CPU contention, scan pollution, write amplification과 no-victim latency를 교환한다. Pathology는 working set>pool, dirty tail saturation, pinned leak, waiter-bearing hot pages와 overly small/large zones다.

Assertion은 impossible-state diagnostic이지 production cleanup이 아니다. Full-disk/corruption retry는 동일 operation의 partial logical state를 고려해야 하며 page-buffer layer가 무조건 retry하면 안 된다.

Known limits, compatibility choice와 readiness

Known compatibility limits: ABI/byte-layout, exact timing, strict fairness, performance parity, every transitive caller, every storage-device failure와 PostgreSQL/MySQL runtime은 scope 밖이다. Current CUBRID early-error behavior는 CUBRID-C010에 source-confirmed로 기록했다. External semantic reimplementation은 lock-free optimization을 생략할 수 있고 error handling은 strict-compatibility 또는 hardened-rollback mode를 명시해야 한다.

READY WITHIN DECLARED SCOPE

이 선언은 external page-buffer behavior와 declared representative caller/recovery/flush paths를 source 없이 재구현할 수 있다는 뜻이다. Drop-in ABI, storage byte-format, timing 또는 performance equivalence를 뜻하지 않는다.

요약과 발표 전환

Identity, ownership, concurrency, durability, release의 다섯 축을 Interface, ADT, total lifecycle, failure matrix와 conformance oracle로 닫았다. 이제 static quiz로 prediction을 검증하고 live grill에서 source 없이 causal chain을 방어한다.
