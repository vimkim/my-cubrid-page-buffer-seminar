학습 목표와 concrete scenario

네 실험의 hypothesis, command, observation, control, alternative와 not-proven을 평가한다.

질문: counter 값 하나가 source branch와 physical I/O를 동시에 증명할 수 있는가?

직관: 한 page journey를 identity, ownership, concurrency, durability, release 순서로 따라가며 각 abstraction을 exact state와 guard로 교체한다.

Surprising moment — ioreads ≠ physical disk I/O

Num_data_page_ioreads는 이름과 달리 storage device 완료 횟수가 아니다. page_buffer.c:8497에서 counter를 먼저 올린 뒤 dwb_read_page()를 시도하고, DWB에 없을 때만 fileio_read()로 내려간다. 따라서 같은 +1이 DWB error, DWB hit 또는 DWB miss 뒤 main-volume read attempt 중 어느 결과가 됐는지 counter만으로 구분되지 않는다.

Buffer miss가 counter를 1 증가시킨 뒤 DWB read를 시도한다. DWB hit이면 거기서 끝나고, miss이면 main-volume fileio_read로 간다. 오류 branch는 counter가 이미 증가한 뒤 read source 없이 반환할 수도 있다. Aggregate counter는 VPID와 실제 device I/O 여부를 저장하지 않는다.
