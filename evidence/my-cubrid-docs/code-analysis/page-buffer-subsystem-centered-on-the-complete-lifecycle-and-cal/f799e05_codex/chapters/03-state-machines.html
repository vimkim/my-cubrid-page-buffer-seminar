03. 하나의 state machine으로 합치지 마라

학습 목표와 concrete scenario

startup, steady state, abort, shutdown과 restart의 legal/illegal transition을 재구성한다.

질문: dirty resident page를 가진 server가 clean shutdown하거나 crash할 때 어떤 state가 보존 또는 재생성되는가?

직관: 한 page journey를 identity, ownership, concurrency, durability, release 순서로 따라가며 각 abstraction을 exact state와 guard로 교체한다.
