01 · The substitution test

Classify the protocol before comparing speed

Two functions can both return something typed like page bytes while granting completely different rights. Ask these questions before substituting one for another.

  1. Owner: which subsystem is allowed to use this protocol?
  2. Location: are the bytes in a resident frame, a caller area, or a private copy?
  3. Guard: what prevents conflicting change while the bytes are used?
  4. Accounting: does it create a BCB fix, a per-thread holder, both, or neither?
  5. Cleanup: which exact operation ends the lifetime?
  6. Permission: may the caller mutate, dirty, flush, invalidate, or only inspect?

Interface choice follows the complete owner protocol—not the C type of its return value.

03 · Area-copy hazards

Verify supported modes at the implementation boundary

VS-02 and VS-03 are uncertainty-registry identifiers for pinned source drift. They are not runtime error codes.

04 · Observation versus authority

Approximate signals may suggest work; they cannot permit it

Waiter queries, SHOW rows, and statistics answer diagnostic or scheduling questions with path-specific synchronization. For example, pgbuf_peek_stats() intentionally copies BCB flags without locking each BCB, so concurrent changes can produce an approximate snapshot.

Safe use: “This count suggests replacement pressure; inspect the protected path.”
Unsafe use: “The count is zero, therefore this page may be deallocated or reused.”

VS-04 routes prototype-name drift in pgbuf_peek_stats(); VS-05 routes approximate snapshot semantics. Neither value replaces the mutex, latch, identity recheck, or owner protocol that authorizes a state transition.

Verified mechanism: page_buffer.c:14748–14847,17323–17530.

05 · Dead or incomplete interface

Availability requires a complete implementation path

At the pinned revision, release headers macro-map and declare pgbuf_fix_without_validation_release(), but a repository-wide search locates no definition or caller. VS-01 records that verified source fact.

Do not characterize it as a faster bypass. Calling it would fail at link time unless the target branch supplies a definition and a complete, tested owner protocol.

Interface inventory: declaration at page_buffer.h:320–326; availability status belongs to VS-01.

07 · Retrieval practice

Reject four unsafe substitutions

Prompt

A review proposes four shortcuts: use simple fix where a temporary page may be written; mutate and unfix a heap scan-copy; use copy_from_area(..., false) for a logged update; and deallocate when approximate statistics show no users. The patch also calls pgbuf_fix_without_validation() in a release build.
