Two preparation paths, one contract

Caller intent

  1. Fetch mode: allocation/residency knowledge.
  2. Latch mode: permitted content access.
  3. Condition: wait or reject on conflict.

NULL without a grant creates no unfix debt.

Resident hit

  1. Observe matching hash candidate.
  2. Lock its BCB.
  3. Recheck the VPID under protection.
  4. Retry chain if the reusable slot was rebound.

Cold miss

  1. Register first to become VPID load owner.
  2. Obtain and assign an unpublished provisional BCB.
  3. OLD_PAGE: DWB then volume; NEW_PAGE: skip old-byte I/O and initialize Module metadata while the payload remains caller-owned.
  4. Confirm, grant, publish, release load lock.
  5. Wake waiters; each retries and earns its own debt.

Shared success

  1. Requested VPID is resident.
  2. Requested latch is granted.
  3. Global fcnt and thread holder include the grant.
  4. Borrowed PAGE_PTR owes one matching unfix.
