Durability vocabulary

Two-generation worked example

Two LSA roles

  • Page LSA: latest logged change included in the image; copied value is the WAL force target.
  • Oldest-unflush LSA: oldest logged change unpropagated in the generation; checkpoint lower-bound material.

Flag algebra

  • Open G: set FLUSHING; clear old DIRTY.
  • Writer creates G+1: set DIRTY again.
  • G success: clear only FLUSHING.
  • Ordinary G failure: restore retryable state; wake waiters.

Ordinary success route

  1. Validate BCB identity.
  2. Set FLUSHING; clear captured DIRTY.
  3. Copy stable bytes and LSAs.
  4. Release BCB protection.
  5. Force WAL through copied page LSA.
  6. Submit via DWB or direct write.
  7. Reprotect, clear FLUSHING, wake/handoff.

Review questions

  1. Which generation does each byte/LSA/flag describe?
  2. What exact persistence boundary was observed?
  3. Can a writer publish G+1 while G is in flight?
  4. Does failure preserve retryable debt and wake waiters?
  5. Is a source concern being promoted beyond its evidence?
