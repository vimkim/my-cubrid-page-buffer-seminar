Ordered refix route

Comparison coordinates

  1. Access-method group
  2. Rank: header < normal < overflow
  3. VPID within equal group/rank
  4. No known group sorts last

Conditional-failure rule

  • Held H before request R → keep fixed.
  • Held H after R → fully unfix and mark watcher.
  • Unknown request group → release held set required by protocol.
  • Fix R unconditionally; refix released pages sorted.
