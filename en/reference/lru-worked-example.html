LRU worked example: admission and reuse

Follow the same frame through a miss, first placement, and another access. Predict each transition before opening its explanation. This first sequence ends with a resident LRU1 page that has been read again but has not moved.

0 · A window into a larger pool

Constructed trace, not a runtime observation. Rules are pinned to CUBRID f799e05d77d5300c6ea5753b4a6cc7caee6d8912. Textbook exact LRU puts each accessed item at the most-recent end. Here, inspect the actual fix and final-unfix branches before predicting movement.

Server mode, num_buffers = 32768; shared_lists = 32; private_lists = 4 (explicit private-chain count). Context A carries private-local p = 0, full list 32; context B carries p = 1, full list 33. B is idle during these steps. Pages P and R form A's small working set; a later sequential scan and B's access will put pressure on it. P and R are existing valid disk pages, initially absent from the resident hash. F42 and F43 are permanent frame/BCB pairs, not page IDs.

Initially 2,000 pages are resident: 100 in private list 32 and 1,900 in shared list 0. All other lists are empty. INVALID has 30,768 nodes, headed by F42 then F43. Shared list 0 has all its nodes in LRU3. Private list 32 has 2/48/50 nodes in LRU1/2/3; its LRU1 order is H1 → H2. H2 is bottom_1; the last of the 48 LRU2 nodes is bottom_2. The 50 LRU3 nodes follow it.

List 32 has quota 1,000 and LRU1/LRU2 thresholds 50/50. These snapshot values stay fixed through this sequence.

Derive the quota and shared thresholds

A prior accepted quota pass has private_pages_ratio = 0.5 and all smoothed private activity assigned to list 32. Thus all_private_quota = 2000 * 0.5 = 1000, list 32 has quota = 1000, and each private protected-zone threshold is 1000 * 0.05 = 50. Other private quotas are zero. Shared thresholds are floor((32768 - 1000) / 32) = 992, then floor(992 * 0.4) = 396 and floor(992 * 0.05) = 49. These are snapshot inputs and derived policy values, not miniature-pool substitutions.

All unmentioned pages remain idle. No daemon/quota pass, new context access, error, waiter, dirtying, flush, reservation, or vacuum hint intervenes. Each event completes before the next. P and R remain clean, non-hot, with no avoid-victim or move-to-bottom flag. AOUT is disabled. List 32 starts at tick_list = 1000; the accepted quota epoch stays adjust_age = 10. Fresh F42/F43 have hit_age = 0; list 32's current lru_hits = 0. List ticks and quota epochs are different clocks.

Implementation policy: list topology, quota/threshold derivation. See the quantity derivation and unfix/epoch evidence.
