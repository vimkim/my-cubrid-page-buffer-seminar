FINAL PAGE-BUFFER SEMINAR · 2026-10-13

Session 3 · Making room safely for the next page

A page is a block of database data. The buffer pool is a fixed set of memory slots called frames, each able to hold one page. A request needs a page that is absent, but every frame is occupied. Some pages in memory still have changes to write. How can the request safely obtain a frame?

Chapters 01–07 follow CUBRID's writing and background work. Chapters 08–11 compare PostgreSQL's way of choosing and protecting frames. Chapter 12 follows a request through reuse and asks which observations explain a stall.
