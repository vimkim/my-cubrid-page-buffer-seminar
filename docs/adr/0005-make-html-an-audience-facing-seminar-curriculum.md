# Make the bilingual HTML an audience-facing seminar curriculum

Use the bilingual HTML directly with Seminar participants as a capability-gated, multi-session curriculum rather than as a personalized course that coaches its presenter. The curriculum has no fixed total duration; it uses 90-minute audience-facing lectures, covers Core and Advanced mechanisms plus applied maintainer work, and completes only when participants produce the required source-tracing, scenario, diagnostic, change-analysis, and technical-defense evidence.

## Consequences

The Korean site is the primary live experience while English remains the canonical content source under ADR 0004. Existing page URLs remain stable, the current 25 lesson pages are the provisional lecture set, and useful reference pages become a Topic library; the public syllabus, Synthesis workshops, Audience checkpoints, progressive disclosure, and Presentation mode must work both when projected and when read independently. Personalized learner state, teaching-agent routing, keyword-based mastery claims, and presenter-only directives leave audience pages; useful delivery guidance moves to one private Presenter runbook. The canonical Markdown Maintainer Guide remains a separate evidence product and changes only when review finds a genuine technical or explanatory defect.
