없는 page 하나를 처음부터 끝까지 설명하기

P 요청 → resident 조회 → 없으면 frame 확보 → invalid 자리가 우선이고, 없으면 domain과 적격 후보 선택 → 보호 아래 재검사 → 이전 mapping 제거 → P 준비 → 접근 권한 획득 → 사용 후 unfix. 변경이 남으면 WAL 순서를 지키는 cleaning이 이후 재사용을 준비할 수 있다. Flush 완료 자체가 eviction은 아니다.
