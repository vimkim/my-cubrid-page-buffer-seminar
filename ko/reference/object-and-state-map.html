Ownership 개요

Object와 lifetime

VPIDLogical identity 값이며, resident가 아니어도 존재할 수 있습니다.
BCB재사용되는 pool control입니다. 현재 identity는 바뀔 수 있습니다.
Frame재사용되는 pool byte 영역입니다. 내용은 resident generation을 따라갑니다.
PAGE_PTR빌려 쓰는 view입니다. 대응하는 unfix에서 사용이 끝납니다.
Global fcnt하나의 BCB에 부여된 모든 fix debt입니다.
Thread holder이 thread가 가진 BCB debt와 중첩 fix_count입니다.

네 좌표 확인표

  1. Identity / residency: 이 BCB/frame은 어느 VPID를 나타내는가?
  2. Ownership: 일반적인 재사용을 막고 있는 fix는 무엇인가?
  3. Concurrency: 지금 누가 byte를 읽거나 변경할 수 있는가?
  4. Durability / propagation: 어느 generation을 전파해야 하며, recovery boundary는 어디인가?

세 가지 lifetime

  • Pool: BCB와 frame의 allocation 기간.
  • Resident generation: 현재 VPID-to-frame mapping이 유효한 기간.
  • Borrow: fix 성공부터 대응하는 unfix까지.

혼동하면 안 되는 네 쌍

  • Fixed와 resident는 같은 뜻이 아닙니다.
  • DIRTY와 durable은 같은 뜻이 아닙니다.
  • Unfix와 flush는 같은 동작이 아닙니다.
  • Eviction과 deallocation은 같은 동작이 아닙니다.
