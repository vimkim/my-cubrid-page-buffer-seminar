6단계 mutation spine

두 가지 protection

  • Page latch: 현재 resident byte에 대한 access. watcher를 release/transfer하면 끝난다.
  • Transaction lock: logical class/row protocol. transaction policy에 따라 끝난다.
  • 하나를 hold한다고 다른 하나도 hold한다는 뜻은 아니다.

성공 path의 order

  1. logical lock을 준비하고 획득한다.
  2. destination을 acquire한 뒤 validate한다.
  3. resident page format을 mutate한다.
  4. recovery log를 append하고, 필요하면 page LSA를 전진시킨다.
  5. resident generation을 DIRTY로 표시한다.
  6. 모든 watcher를 transfer하거나 release한다.

같은 뜻이 아닌 네 쌍

  • WRITE latch ≠ logical ownership
  • Mutation ≠ recovery logging
  • Page LSA ≠ DIRTY publication
  • Unfix ≠ commit or flush

Exit ledger의 column

  1. 정확한 exit seam
  2. 이미 acquire/create한 state
  3. consumer, transfer, cleanup owner
  4. 남은 recovery/retry consequence
  5. evidence boundary 또는 helper dependency
