Mission 완료 audit

목표를 완료하려면 어떤 evidence가 필요한가

  1. 통합 Core retrieval: object map, page journey, 독립적인 axis, caller boundary, generation, replacement, evidence, latch wait를 하나로 설명합니다.
  2. Pinned source 역량: target source에서 성공한 fix/release, 대표 mutation, generation 하나의 flush, 안전한 frame reuse를 추적합니다.
  3. Advanced 전이: promotion/ordered access, pressure/progress, redo/lifecycle, specialized interface, failure proof를 Core invariant로 설명합니다.
  4. 운영 navigation: 변경, symptom, evidence status, source/invariant 질문을 하나씩 실시간으로 올바른 문서에 연결합니다.
  5. Maintainer review evidence: 일관된 독립 설명, counterexample, evidence label, 공격적 질문 방어, 기록된 동료 feedback을 갖춥니다.

과정이 준비됐다는 사실은 교육 system의 준비도를 보여 줍니다. Maintainer의 준비도는 학습자가 직접 만든 산출물로 입증해야 합니다.

이 matrix는 점수표가 아니라 routing과 evidence audit입니다. 제출된 작업, 바로잡은 오개념, source trace, 동료 review receipt, 확인된 Mission 변경이 있을 때만 학습자 상태를 갱신하세요.
