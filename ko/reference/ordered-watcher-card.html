Ordered refix 흐름

정렬 기준

  1. access-method group
  2. rank: header < normal < overflow
  3. group/rank가 같으면 VPID
  4. group을 알 수 없으면 마지막

Conditional fix 실패 규칙

  • held H가 request R보다 앞이면 → fixed 상태를 유지한다.
  • held H가 R보다 뒤이면 → 완전히 unfix하고 watcher에 표시한다.
  • request group을 알 수 없으면 → protocol이 요구하는 held set을 release한다.
  • R은 unconditional fix하고, release한 page는 정렬 순서대로 refix한다.
