Return type이 익숙해 보여도 다른 protocol의 ownership, guard, permission, cleanup이 함께 따라오는 것은 아닙니다.

세 가지 access form

대체 가능성 확인 gate

  1. 권한을 가진 owner가 누구인지 적습니다.
  2. 반환된 byte가 어디에 있는지 확인합니다.
  3. 변경을 막는 guard가 무엇인지 적습니다.
  4. fcnt와 holder state를 빠짐없이 계산합니다.
  5. 정확히 짝을 이루는 cleanup을 적습니다.
  6. 허용되는 operation을 나열합니다.
  7. Evidence와 revision을 표시합니다.
